QuotationFactory owns the quotation project. Odoo owns order confirmation, manufacturing and accounting. A Unified Namespace (UNS) is a shared data layer for connected production systems. QF2Odoo does not by itself connect machines or enable shop-floor feedback.

<Note>
  These guides cover Odoo 19. Available screens and exchanges depend on your installed release and configuration.
</Note>
