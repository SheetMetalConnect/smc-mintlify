Sheet Metal Connect integrations connect quotation and production systems, either directly or through a shared data layer. These guides explain what each integration does and how your team uses it.

QuotationFactory owns the quotation project. Odoo owns order confirmation, manufacturing and accounting. A Unified Namespace (UNS) is a shared data layer for connected production systems. QF2Odoo does not by itself connect machines or enable shop-floor feedback.

<Note>
  The Odoo guides cover Odoo 19. Available screens and exchanges depend on your installed release and configuration.
</Note>
