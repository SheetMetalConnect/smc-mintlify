## One source for each decision

QuotationFactory holds the quotation project. Odoo controls its own order confirmation, manufacturing and accounting. A **Unified Namespace (UNS)** is the shared data layer through which connected production systems exchange information.

Each integration has its own purpose. Using QF2Odoo does not by itself connect your machines or enable shop-floor feedback.

<Note>
  Available screens and exchanges depend on your installed release and configuration. These guides distinguish the core workflow from optional capabilities.
</Note>
