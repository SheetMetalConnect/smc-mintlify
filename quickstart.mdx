Start with one example your team can recognize. Find it in the source system, follow it into Odoo and check the result in the normal business record.

[Nederlands](/nl/quickstart)

<Steps>
  <Step title="Choose the integration">
    For a quotation exported from QuotationFactory, use [QF2Odoo](/qf2odoo/overview). For Odoo manufacturing information and shop-floor feedback, use the [Odoo UNS Connector](/odoo-uns/overview).
  </Step>
  <Step title="Find the record">
    For QF2Odoo, open the Odoo quotation using the returned reference. For the UNS connector, open the manufacturing order and its work order in Odoo. The guides show the added tabs and the standard Odoo records.
  </Step>
  <Step title="Check the result">
    Compare the source reference and quantities. A successful transfer is not the same as order confirmation, production completion or payment. Check each result in the relevant Odoo record.
  </Step>
</Steps>

<Columns cols={2}>
  <Card title="Quotation to payment" href="/qf2odoo/workflow">
    Review the draft, then follow the standard Odoo sales process.
  </Card>

  <Card title="Production feedback" href="/odoo-uns/workflow">
    See what the shop floor reported and check its effect in Odoo.
  </Card>
</Columns>

If the result is missing, start with [QF2Odoo troubleshooting](/qf2odoo/troubleshooting) or [UNS troubleshooting](/odoo-uns/troubleshooting). Your administrator can confirm the enabled exchanges and access rights.
