Start with one example your team can recognize. Find it in the source system, follow the configured exchange and check the result in the receiving system.

[Nederlands](/nl/quickstart)

<Steps>
  <Step title="Choose the integration">
    Choose the route that matches the source and result:

    - [QF2Odoo](/qf2odoo/workflow): QuotationFactory export to an Odoo draft quotation.
    - [Odoo UNS Connector](/odoo-uns/workflow): Odoo production information and configured shop-floor feedback.
    - [QF2Oseon](/qf2oseon/workflow): QuotationFactory export to Oseon and Boost.
    - [QF2UNS](/qf2uns/workflow): QuotationFactory export and attachments to the UNS for connected consumers.
    - [Oseon2UNS](/oseon2uns/workflow): Oseon data to the UNS and configured write-back where enabled.
  </Step>
  <Step title="Find the record">
    Use the source reference to find the project, order or data in the receiving system. The selected guide explains where to check the result.
  </Step>
  <Step title="Check the result">
    Compare the source reference and quantities. A successful transfer is not the same as order confirmation, production completion or payment. Check each result in the relevant receiving system.
  </Step>
</Steps>

The selected workflow above explains the next step and checks for a missing result.
